## Task 5: Strategy choices
- **Blog post — SSG:** blog content is mostly stable, so HTML can be generated at build time and served quickly; rebuild when content changes.
- **Live stock-price dashboard — CSR:** the screen is highly interactive and depends on frequently changing client-side data; fetch updates in the browser. A server-rendered initial snapshot could also be appropriate if initial visibility/SEO mattered.
- **User account page — SSR:** personalized content can be rendered per request after identifying the user, avoiding a shared static page containing account-specific data. Ensure authorization and privacy checks happen on the server.
