# Web Engineering Lab

This project demonstrates native form validation, accessible error messages, and TypeScript strict checking.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run typecheck`.
5. Run `npm run build`.
6. Open `index.html` with VS Code Live Server.

The TypeScript build writes JavaScript files into `public/`. The page loads the generated JavaScript modules.
